This quickstart walks you through everything from installing Make It Rain to seeing your first Raindrop bookmarks appear as Markdown notes in your Obsidian vault. The entire process takes about five minutes. If you want deeper detail on any step — manual installation, advanced settings, or template customization — follow the links at the bottom of this page.

<Steps>
  <Step title="Install Make It Rain">
    Open Obsidian and go to **Settings → Community Plugins**. If you see a prompt about Safe Mode, turn it off. Click **Browse**, type **Make It Rain** in the search box, then click the result, click **Install**, and finally click **Enable**.

    <Note>
      Make It Rain requires Obsidian 1.13.0 or later. If the Install button is greyed out, update Obsidian first.
    </Note>
  </Step>

  <Step title="Generate your Raindrop.io API token">
    You need a personal API token so Make It Rain can read your Raindrop account.

    1. Open [app.raindrop.io/settings/integrations](https://app.raindrop.io/settings/integrations) in your browser.
    2. Scroll to **For Developers** and click **+ Create new app**.
    3. Enter any name — for example, `Make It Rain` — and click **Create**.
    4. Click the app name to expand it, then click **Create test token**.
    5. Copy the token to your clipboard. It starts with `eyJ` and is quite long.

    <Warning>
      Treat this token like a password. It grants read access to your entire Raindrop account. Do not share it or commit it to version control.
    </Warning>
  </Step>

  <Step title="Enter the token in Make It Rain settings">
    Back in Obsidian, open **Settings → Community Plugins → Make It Rain** (click the gear icon next to the plugin, or navigate to the plugin's settings tab).

    Paste your token into the **API Token** field, then click **Verify Token**. You should see a success notice confirming the connection. Optionally, set a **Default Folder** to control where imported notes are saved in your vault.
  </Step>

  <Step title="Open the import modal">
    Open the Command Palette with `Ctrl+P` (Windows/Linux) or `Cmd+P` (macOS) and type **Fetch raindrops**. Select **Fetch raindrops (filtered)** from the list.

    The import modal opens and loads your Raindrop collections. Select the collection you want to import from the dropdown. You can also filter by tag or content type if you want to narrow the import.
  </Step>

  <Step title="Import your bookmarks">
    Click **Fetch raindrops**. Make It Rain fetches your bookmarks from the Raindrop API and writes each one to your vault as a Markdown file. A status notice shows progress. When it completes, your notes appear in the folder you configured — or the vault root if you left the default folder blank.
  </Step>
</Steps>

## What an imported note looks like

Each bookmark becomes a Markdown file with YAML frontmatter containing the full Raindrop metadata, followed by a structured body. Here is an example of what a typical article import produces:

```markdown
---
title: "Understanding React Hooks"
source: https://example.com/react-hooks-deep-dive
type: article
created: 2024-03-10T09:15:00Z
lastupdate: 2024-03-11T14:42:00Z
id: 123456789
collectionId: 4567890
collectionTitle: "Web Development"
collectionPath: "Learning/Web Development"
collectionGroup: "CORE KNOWLEDGE"
tags:
  - react
  - javascript
  - frontend
banner: https://example.com/images/react-cover.jpg
---

![Understanding React Hooks](https://example.com/images/react-cover.jpg)

# Understanding React Hooks

## Description

A deep dive into the React Hooks API and how to replace class-based lifecycle methods with functional components.

## Notes

Great reference — revisit before the team migration sprint.

## Key Points

> Hooks let you use state and other React features without writing a class.
> The useEffect Hook lets you perform side effects in function components.

## Details

- **Type**: Article
- **Domain**: example.com
- **Created**: March 10, 2024

[Read Article](https://example.com/react-hooks-deep-dive)
```

The exact output depends on your active template. The default template includes all available metadata; you can customize every section using the template engine.

<Tip>
  If you import the same collection regularly, save your settings as a **preset**. Open the import modal, configure your filters and folder, then click **Save as Preset**. Make It Rain registers a dedicated Command Palette entry for that preset — run it in one step without reopening the modal.
</Tip>
